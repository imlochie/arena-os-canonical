---
name: Spaces product expectations
description: Spaces is intended to be a persistent AI-operated Linux working environment, not a browser-task preset collection.
---

Spaces should provide full Linux environmental workspaces for AI agents, locally or through another workable host. The user expects an agent that actually builds things, navigates the internet, plays selected YouTube videos repeatedly for personal use, creates accounts to automate tasks, and can install itself when directed. These are capability examples, not a request to implement narrow presets.

**Why:** The user described the intended product as “a jarvis that can actually do tasks like replit,” rather than a shell that explains tasks.

**How to apply:** Evaluate actual model-to-tool execution, persistent environments, dependency installation, browser/terminal visibility, resumable tasks and usable results together. Distinguish a workspace directory or host command fallback from an isolated Linux environment. Keep installations and consequential external actions under explicit user control; never imply that a configured tool or offline planner proves autonomous execution.
