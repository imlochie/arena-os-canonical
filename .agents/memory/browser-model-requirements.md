For Windows browser tasks, the user wants “whatever is free and unlimited and works on my laptop.”

**Why:** The user stated this requirement when asked which real model to target.

**How to apply:** Prefer a local inference runtime without API fees or provider quotas. Do not substitute a cloud free tier with usage limits or call the deterministic offline engine a model. Hardware suitability and task quality still need to be measured on the actual laptop; do not promise speed or reliable automation from a model's advertised size alone.
