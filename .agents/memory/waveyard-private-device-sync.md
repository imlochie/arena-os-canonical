---
name: Waveyard private device sync
description: User expectations for pairing and syncing a Waveyard live session across personal devices.
---

The user wants to scan a QR code to bring a second device into the live session, with privacy—especially personal privacy—as a priority. Prefer direct laptop-hosted pairing or a no-cost encrypted option over dependence on paid cloud services. Session controls should not require uploading audio or the user's library.

**Why:** Multi-device sync should make the session easier to use without creating a cloud account, paid service, or new exposure of private audio and library data.

**How to apply:** Keep the pairing flow direct and understandable, explain exactly what crosses the network, and distinguish local-network support from true cross-network pairing. Never imply cross-network availability or end-to-end privacy without verifying the implemented transport.
