# Design mockups

These images are **design references / visual targets** for LUMA's UI, not
screenshots captured from a running build. They illustrate the intended
dark-first, minimal, photographic look and the layout that the implemented
screens follow (`app/(tabs)/index.tsx`, `app/editor.tsx`).

Because the app depends on native modules (Skia, Reanimated, Expo Camera), real
device screenshots must be captured from an EAS build running on an iPhone — see
the build instructions in the top-level `README.md`.

- `camera.png` — Camera (default landing) screen
- `editor.png` — Non-destructive editor with preset carousel + intensity
