# Agent instructions

Read [docs/HANDOFF.md](docs/HANDOFF.md) before doing anything: it has the
current status, ordered priorities, ground rules and the branch/PR ledger.
Also see [README.md](README.md) for layout and commands.

- `main` is canonical. Never delete branches or rewrite history.
- Keep PR descriptions truthful; keep diffs focused.
- Do not claim verification without a passing test or CI run.
- Update `docs/HANDOFF.md` in every PR that changes status or priorities.
- Arena is proprietary (see `LICENSE`); do not copy its code elsewhere.
